# 📝 To-Do List Web App

A clean and responsive To-Do List web application built with modern frontend technologies.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by All, Active, and Completed
- Dark mode
- Responsive design
- Task counter
- Empty-state handling

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## 📚 What I’m Learning

This project is part of my frontend development journey. I'm using it to practice:

- React state management
- Event handling
- TypeScript
- Component-based development
- Conditional rendering
- Array methods such as `map()` and `filter()`
- Responsive UI development
- Frontend architecture and data flow

## 🎯 Project Goal

The goal of this project is to build a simple but properly structured frontend application while understanding how the different parts of a modern web application work together.
